🎬 Demo Splash & Gaya Loading

Kalau 5 kotak di bawah ini **beranimasi** (gerak) → CSS bener, berarti di app lu cuma **caching** (file lama). Kalau di sini juga kagak gerak → bug CSS.

📌 Tentang "splash belum full sampai status bar":
Di browser biasa (terutama iPhone/Safari), area address bar + status bar itu UI browser — tidak bisa ditutup halaman. Yang bisa diwarnain cuma lewat theme-color (berlaku di Android Chrome & PWA).

Solusi full-screen beneran: install jadi PWA (Menu → "Tambahkan ke Layar Utama" / "Add to Home Screen"). Di mode PWA, status bar ikut warna splash & halaman full sampai atas.
